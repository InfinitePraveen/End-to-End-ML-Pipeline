# Data

This project uses the California Housing dataset provided through scikit-learn.

The notebooks download/load the dataset through the scikit-learn dataset API instead of storing a large copy inside the repository.

This keeps the GitHub repository small and makes the project easy to reproduce on another computer.

The dataset contains housing-related features such as:

- Median income
- House age
- Average rooms
- Average bedrooms
- Population
- Average occupancy
- Latitude
- Longitude

Target:

- Median house value
